# 简历工坊 · 无界面简历产出

让 AI 代理跳过编辑器界面完成简历产出全流程。产出物是一份 `resume JSON`——它是
简历工坊编辑器的原生数据格式：可以直接导入编辑器继续可视化微调，也可以经应用服务
无界面导出矢量 PDF，或转写成 Markdown。

## 前置条件

- **校验**（必选）：仓库根目录即可，校验脚本零依赖，`node` ≥ 18。
- **PDF 导出**（可选）：本机或远端跑着应用服务，且设置了 `PDF_ACCESS_PASSWORD`
  （Bearer 通道口令）。没起服务也能交付——JSON 导入编辑器后用「打印导出」兜底。
- **Markdown 交付**（可选）：纯文本转写，无任何依赖。

## 快速路由

| 用户意图           | 路径                                      | 需要加载                     |
| ------------------ | ----------------------------------------- | ---------------------------- |
| 从零写一份简历     | 工作流全部步骤                            | `references/data-schema.md`  |
| 改 / 润色已有 JSON | 读原文 → 修改 → 校验 → 导出               | `references/data-schema.md`  |
| 按 JD 定制         | 先通读 JD 提关键词 → 按关键词重写经历要点 | `references/data-schema.md`  |
| 导出 PDF           | 工作流第 4 步                             | `references/headless-api.md` |
| 只要 Markdown      | 工作流第 1-3 步后改走 Markdown 转写       | 无需额外文件                 |

## 工作流

### 第 1 步 · 收集信息

已给素材（旧简历、LinkedIn 文本、口述）→ 提取结构化事实，**不编造**经历与数据。
缺关键信息（姓名、联系方式、目标岗位）→ 先问，不要猜。

### 第 2 步 · 构建 JSON

复制 `assets/resume-template.json` 为工作文件，逐模块填充。结构、枚举值、长度上限
**必须**遵守 `references/data-schema.md`——那是服务端白名单的忠实转述，越界的值不会
报错，而是被静默清洗成默认值（比如非法颜色回退纯黑、超长文本被截断）。

要点写法直接决定简历质量：

- 每条经历 3-5 条要点，格式「动作 + 做了什么 + 可量化结果」（如「主导 X，Y 从 A 降至 B」）；
- 经历按时间倒序；应届生用实习/项目/校园经历替代工作经历；
- 没有数据支撑的自我评价建议整段删掉，编造的数字不如不写。

### 第 3 步 · 离线校验

```bash
RESUME_SKILL="<skill_directory>"   # 本 SKILL.md 所在目录
node "$RESUME_SKILL/scripts/validate_resume.mjs" resume.json
```

脚本与服务端 `/api/pdf` 跑**同一份**白名单（`server/sanitize.js`），输出结构与统计
外加质量警告（空要点、缺联系方式、疑似编造占位符等）。**警告清零或确认可接受后
才算过稿**；校验失败必须回第 2 步修，带病提交会被服务端 400 或静默清洗。

### 第 4 步 · 交付

按用户要的格式三选一（细节见 `references/headless-api.md`）：

1. **矢量 PDF**：`POST /api/pdf`（Bearer 口令），响应体即 PDF 二进制，存为文件交付；
2. **JSON**：把校验通过的 `resume.json` 交给用户，编辑器「导入 JSON」即得完整可编辑简历；
3. **Markdown**：从 JSON 纯文本转写（# 姓名 / ## 模块标题 / - 要点），ATS 友好，零依赖。

## 硬性约束

- 文本里**永远不要写 HTML**——服务端剥标签不转义，写了就丢内容；
- 图片只接受 `data:image/png|jpeg|webp|gif;base64,...`，单张 ≤ 3MB；外链 URL 一律会被清空；
- **不要生成 `id` 字段**——服务端一律重新生成，写了也白写；
- 一页纸是默认预期：模块 ≤ 7 个、每模块条目 ≤ 5 条时版面最稳，超出先问用户是否真要两页；
- PDF 导出计入额度（每主体每日 10 次），同一内容 10 分钟内重复导出不扣额度——
  修小错后直接重导，不必心疼。
